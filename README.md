# Hola, soy EVER CHIPANA NUÑEZ 👋

### 🛡️ Arquitectura de Redes | Infraestructura | Ciberseguridad

🎓 **Estudiante de Ingeniería de Sistemas** en la Universidad Nacional de San Cristóbal de Huamanga (UNSCH).
Me especializo en el diseño, configuración y seguridad de infraestructuras de red, respaldado por una base sólida en desarrollo de software para crear soluciones integrales, seguras y automatizadas.

---

### 🚀 Sobre mí

- 🔧 **Administración de Servidores:** Despliegue y configuración de servicios en **Ubuntu Server** (Apache, FTP, SSH) implementando reglas de firewall (UFW).
- 🌐 **Redes y Enrutamiento:** Diseño de topologías, cálculo de subredes (VLSM) y configuración de interfaces y protocolos en equipos mediante **Cisco Packet Tracer**.
- 🔒 **Ciberseguridad:** Implementación de cifrado híbrido con **OpenSSL**, análisis de tráfico con **Wireshark** y estudio de arquitecturas Zero Trust y seguridad en aplicaciones (OWASP).
- 💻 **Desarrollo y Datos:** Creación de aplicaciones web con arquitecturas limpias usando **ASP.NET Core (C#)**, automatización de pruebas con **pytest** y diseño de reportes de inteligencia de negocios en **Power BI**.
